# Циолковский — сайт киберспортивного клуба

Готовый **статический сайт для GitHub Pages**, собранный из согласованной версии лендинга.
Сборка не нужна: достаточно разместить файлы в репозитории.

## Структура

```text
index.html                 — главная страница
assets/css/style.css       — оформление и адаптивная версия
assets/js/main.js          — переключение зон, меню, popup и остальное поведение
assets/images/*.webp       — фотографии клуба и иллюстрации
.nojekyll                  — указание GitHub Pages не применять Jekyll
README.md                  — инструкция
```

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub (например, `tsiolkovsky`).
2. Загрузите **содержимое архива в корень репозитория**: рядом должны лежать `index.html`, `README.md`, `.nojekyll` и папка `assets`. Не загружайте дополнительную вложенную папку.
3. Откройте репозиторий: **Settings → Pages → Build and deployment**.
4. Установите **Source: Deploy from a branch**, выберите `main` и **/(root)**, затем **Save**.
5. Когда сайт опубликуется, его адрес будет примерно `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/tsiolkovsky/`.
   Если репозиторий называется `ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io`, сайт откроется по `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/`.

## Проверка локально

Из корня сайта выполните `python3 -m http.server 8000`, затем откройте
`http://localhost:8000/` в браузере. Сайт также можно открыть через `index.html`, но локальный сервер лучше для проверки.

## Важно

- Все **изображения** в комплекте; отдельно загружать фотографии не нужно.
- Шрифты Russo One, Exo 2 и IBM Plex Mono подключены через **Google Fonts**, как в согласованном лендинге. Для фирменного отображения шрифтов нужен интернет; при отсутствии доступа используются резервные шрифты.
- Ссылки на Яндекс Карты и отзывы — внешние ссылки, для них также нужен интернет.
- Это статический сайт, поэтому отдельный сервер, база данных и npm-пакеты не требуются. Кнопки звонка используют `tel:`.
- Пути к CSS, JavaScript и изображениям **относительные**, поэтому сайт работает как в корне домена, так и по адресу проекта GitHub Pages.
